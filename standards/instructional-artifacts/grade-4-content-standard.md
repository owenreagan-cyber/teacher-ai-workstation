# Grade 4 Instructional Content Standard

Status: active standard for mechanical + visual validation boundaries.

## Purpose

Define integrity expectations for printable Grade 4 student resources before classroom use.

## Text defaults

| Element | Target size |
| --- | --- |
| Student body text | 12.5–14 pt |
| Directions | 13–14 pt |
| Section headings | 15–18 pt |
| Main titles | 20–24 pt |

## Writing spaces

| Use | Minimum height |
| --- | --- |
| Short word/phrase | 0.35 inch |
| One complete sentence | 0.65–0.85 inch |
| Two or three sentences | 1.25–1.60 inches |
| Paragraph | 2.0–2.75 inches |
| Writing-line spacing | 0.30–0.36 inch |

## Validation layers

1. **Mechanical** — page size, margins, safe boundaries, placeholders, file structure.
2. **Visual** — rendered previews, utilization heuristics, student/key alignment.
3. **Instructional** — teacher judgment for pedagogy, readability, and semantic correctness.

Mechanical PASS does not replace final teacher visual inspection.

## PDF as final contract

The exported PDF is the authoritative print artifact for text-heavy student resources.
