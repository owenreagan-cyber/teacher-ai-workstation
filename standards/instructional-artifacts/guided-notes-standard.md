# Guided Notes Standard

Guided notes are hole-punch friendly, margin-aware student packets with generous writing space.

## Layout

- Left margin widened for binder punch (0.65–0.75 in)
- Section headings visually distinct from body text
- Writing lines or boxes with adequate vertical spacing
- Page numbers on multi-page packets

## Student / teacher key mirroring

- Matching page count when profile requires it
- Matching page dimensions and orientation
- Structural alignment of headings and question numbers
- Teacher answers must not cause major reflow or sentence wrapping in Shurley-style layouts

## Validation

Run `guided-notes-letter` profile with optional `--student` / `--teacher` comparison.

Final classroom readiness still requires teacher visual inspection.

## Automated educational heuristics (Phase 3)

WARN-only checks: fill-in ratio, excessive copying burden, chunking, typography. FAIL reserved for mechanical rules only.
