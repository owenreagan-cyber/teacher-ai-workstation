# Print and Pagination Standard

## Paper

- US Letter: 8.5 × 11 inches (612 × 792 pt)
- Default orientation: portrait
- Print scale: **Actual Size / 100%**

## Margins (standard student resource)

| Edge | Inches |
| --- | --- |
| Top | 0.50 |
| Bottom | 0.50 |
| Left | 0.55 |
| Right | 0.55 |

## Hole-punched guided notes

| Edge | Inches |
| --- | --- |
| Left | 0.65–0.75 |
| Right | 0.50 |
| Top / Bottom | 0.50 |

## Safe content boundary

Essential instructional content must remain at least **0.35 inch** inside the printable margin on every side.

## Pagination rules

- Avoid accidental blank final pages.
- Mixed page sizes require explicit profile permission.
- Multi-page packets should include page numbers when the profile requires them.
- Full-page utilization is desirable, but not at the cost of unsafe edge printing.

## FAIL vs WARN

- **FAIL** — wrong page size, clipping, blank final page, mixed sizes, unresolved placeholders.
- **WARN** — low utilization, large bottom gap, uncertain font embedding, near-boundary content.
