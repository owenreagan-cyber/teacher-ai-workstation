# Worksheet Standard

Worksheets are single- or multi-page Letter PDFs with computation or response space.

## Layout

- US Letter portrait
- Standard margins unless profile specifies guided-notes margins
- Problems grouped with adequate workspace
- No unresolved placeholders

## Student / teacher key

When a teacher key exists, compare pagination and structure before printing class sets.

## Validation profile

Use `worksheet-letter` for math, reading checks, history packets, and science handouts unless a more specific profile applies.

## Manual review

Vertical alignment, symbol rendering, diagram sizing, and instructional sequencing require teacher review.
