# D1 student-data roots: folders no Claude Code session in this repo may read or write.
#
# Empty on purpose. Under D-022 (light profile) school files on Owen's Mac are
# non-sensitive, so ~/.teacher-ai-workstation and ~/Downloads are no longer denied. The file
# stays so a root can be added again later.
#
# One path per line. `~` (your home folder) and globs (*, ?, [..]) are allowed. A folder
# covers everything inside it. Lines starting with # are comments.
#
# Both D1 layers load this file: the hook (from its installed copy next to dev_guard.py) and
# the sandbox (through render_settings.py). If this file is missing or unreadable, D1 denies
# everything under ~/Documents and ~/Desktop until it is fixed. An empty file (comments only)
# denies nothing extra.
#
# To add a root: add a line below, then follow "Add a student-data root" in
# tools/dev_safety/README.md (re-render, copy the profile, re-install).

# Examples (remove the leading # and change the path):
# ~/.teacher-ai-workstation
# ~/Documents/Gradebooks
# ~/Library/CloudStorage/GoogleDrive-*/My Drive/Student Work
# /Volumes/SchoolShare/Students
